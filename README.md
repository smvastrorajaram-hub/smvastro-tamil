# SMV ASTRO SERVICES

## Sri Madurai Veerayah Astro Services

SMV ASTRO SERVICES is a proprietary astrology consultation and horoscope platform.

### Features

- Horoscope and astrology services
- Birth Panchang and astrology calculations
- Daily Panchang
- Astrologer consultation
- Customer Dashboard
- Astrologer Dashboard
- Admin Dashboard
- Razorpay payment integration
- Consultation refund workflow
- Progressive Web App (PWA) support
- Mobile and desktop responsive design
- Multi-language support

### Technology

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Firebase
- Razorpay
- Swiss Ephemeris through the `sweph` Node.js binding
- Astronomy Engine
- Nodemailer

### Deployment

The application may use:

- GitHub for source-code hosting and static frontend deployment
- Render for the Node.js backend
- Firebase for application data and services
- Razorpay for payment and refund processing

### Security

Production secrets must never be committed to this repository.

Do not commit:

- Razorpay API secrets
- Firebase private credentials
- Passwords
- Private keys
- API tokens
- Other confidential information

Use environment variables for production secrets.
